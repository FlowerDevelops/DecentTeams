# Contributing
Decentteams is a project solely maintained by me, at the moment. I would highly appreciate any contributions. Please find stuff you can do in TODO.md, don't go making stuff up

## AI usage
When creating a pull request, I expect your code to be at maximum 10% AI. No exceptions. I myself greatly appreciate clean written code with.

All AI usage has to be **disclosed** using `*// AI start*` and `// AI end`

## Rules
**Always** compile your code and **test** it thoroughly. If possible, make a quick video of it working, for example, since it saves me valuable time and speeds up development.
